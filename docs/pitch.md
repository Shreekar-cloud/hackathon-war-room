# 3-minute demo pitch template

1. **Hook (15 sec):** State the user pain in one memorable sentence.
2. **Problem (30 sec):** Who experiences it, when, and why current options fail.
3. **Solution (30 sec):** Explain the product in plain language.
4. **Live demo (75 sec):** Show one complete user journey. Use realistic sample data.
5. **Impact (20 sec):** Quantify time, cost, access, safety, or quality improvement. Label estimates honestly.
6. **Feasibility (20 sec):** Explain architecture, data, deployment, and next steps.
7. **Close (10 sec):** Repeat the value proposition.

## Judge questions to prepare

- Who is the exact target user?
- What evidence supports the problem?
- What is genuinely novel?
- What happens when the network/API/model fails?
- How do you protect user data?
- What would you build next with one more week?
