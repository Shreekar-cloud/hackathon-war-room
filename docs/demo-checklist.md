# Demo checklist

- [ ] Fresh clone installs successfully.
- [ ] `.env` files are configured locally and are not committed.
- [ ] Backend `/api/health` responds.
- [ ] Frontend can load the API.
- [ ] Create-project flow works with Supabase configured.
- [ ] Fallback behavior is understood if Supabase is unavailable.
- [ ] Demo data is realistic and non-sensitive.
- [ ] Browser zoom, screen resolution, and network are tested.
- [ ] Backup screenshots or a short demo recording are ready.
- [ ] Pitch fits the allocated time.
